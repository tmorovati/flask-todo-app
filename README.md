# Flask Todo App

A simple local todo app built with Python and Flask.

## Features
- Add tasks
- Remove tasks
- View tasks in the browser
- Save tasks locally using CSV

## Tech Stack
- Python
- Flask
- HTML

## How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000

## Project Structure
- `app.py` - Flask app
- `todolist.py` - todo list logic
- `task.py` - task model
- `templates/index.html` - UI template
